agent-orb

一颗会表态的 AI 助手状态球。零依赖、纯 SVG —— 这个页面就是证明：没有构建、没有 npm install，直接 import 源码。
把鼠标在页面上移动，它们都会看着你。

30 秒上手

import { AgentOrb } from '@kubor/agent-orb'

const orb = new AgentOrb(document.querySelector('#orb'))

orb.state = 'thinking'   // 模型在想
orb.state = 'working'    // 长任务跑着，环在转
orb.set('done', 3)       // 好了，角标 3
orb.destroy()            // 卸载时记得清理
